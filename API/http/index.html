Overview

Welcome to the EnUcuz API. This API allows programmatic access to platform resources including products, offers, and user data. All responses are in JSON format.

Base URL
https://api.enucuz.net.tr/api

Authentication

Authentication is handled using secure HTTP-only cookies. You do not need to manually attach tokens to your requests if you are operating within a browser environment that supports cookies.

Cookie Structure
Cookie: access_token=...; refresh_token=...;

POST /login

Authenticate a user and set new session cookies.

Request Body
{ "email": "user@example.com", "password": "password123" }

POST /register

Create a new user account.

Request Body
{ "name": "Jane", "surname": "Doe", "email": "jane@example.com", "password": "securePass!23", "phone": "5550000000" }

GET /refresh/logout

Invalidate session cookies.

GET /profile

Get the currently logged-in user's profile.

Response
{ "user": { "id": 1, "email": "jane@example.com", "name": "Jane", "surname": "Doe", "phone": "5550000000" } }

PUT /profile/update

Update user profile information.

Request Body
{ "id": 1, "name": "Jane", "surname": "Smith", "email": "jane.new@example.com", "phone": "5551112222" }

GET /products

Retrieve a paginated list of products. Use query parameters to filter results.

Query Parameters

Field Type Description
page integer Page number (default: 1)
category integer Filter by category ID
brand integer Filter by brand ID
search string Search term for product name
Response
{ "message": "Successfully", "products": [ { "id": 101, "name": "Wireless Mouse", "price": 250, "stock": 50, "category_id": 1, "brand_id": 2 } ] }

GET /products/{id}

Get detailed information about a specific product.

Response
{ "product": { "id": 101, "name": "Wireless Mouse", "description": "Ergonomic...", "price": 250, "stock": 50 }, "attribute": [] }

POST /products/transactions/new

Create a new product listing. Requires Authentication. This endpoint expects Multipart Form Data.

Form Data

Field Type Description
name string Product name
price integer Price (must be positive)
stock integer Stock quantity
category integer Category ID
brand integer Brand ID
images json JSON array of image URLs

PUT /products/transactions/{id}

Update an existing product's details.

Request Body
{ "price": 300, "stock": 45 }

DELETE /products/transactions/{id}

Delete a product listing.

GET /offers

Get offers received for your products (Incoming).

Response
{ "offers": [ ... ] }

GET /offers/bidder

Get offers you have made on other products (Outgoing).

POST /offers

Make a new offer on a product.

Request Body
{ "productId": 101, "price": 200 }

PUT /offers/{id}

Accept or reject an offer.

Request Body
{ "action": "accept" }

POST /offers/counter/{id}

Respond to an offer with a counter-offer.

Request Body
{ "price": 220 }

GET /reviews

List reviews for a user or product.

POST /reviews

Add a review for a product.

Request Body
{ "product_id": 101, "content": "Excellent quality!", "rating": 5 }

GET /favourites

Get your favorite products.
